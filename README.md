# 🎓 School Student Record Management System

A full-featured Web Application built with Python, Streamlit, and SQLite to manage school student registration, academic profiles, and fee collection with automated receipts.

🌐 **GitHub Pages Documentation:** [Click Here to View Documentation Page](https://rameshbhatiya.github.io/Student-record-management-system/)  
⚡ **Live Interactive Web App:** [Launch Live Streamlit Application](https://studentmanagement6376.streamlit.app/)

---

## ✨ Key Features

- 📊 **Dashboard Analytics:** Real-time view of total students, active classes, collected fees, and total pending fees.
- ➕ **Student Registration:** Add complete profiles (Roll No, Class, Section, Guardian Details, Address, Fee Structure).
- 📋 **Directory & Filters:** View all records with Class and Section multi-filters + Export to CSV.
- 💳 **Fee Collection & Receipt:** Deposit fees, calculate pending balance, and print instant transaction receipts.
- 🔍 **Advanced Search:** Quick search profiles by Roll Number, Name, or Mobile Number.
- ⚙️ **Record Management:** Update existing student profiles or delete records with safety confirmation.

---

## 🛠️ Tech Stack

- **Language:** Python 3
- **Web Framework:** Streamlit
- **Database:** SQLite3
- **Data Handling:** Pandas
