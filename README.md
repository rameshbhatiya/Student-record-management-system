# 🎓 School Student Record Management System

> 🤖 **MADE BY AI** — *Designed & Developed with AI Collaboration*

A full-featured Web Application built with **Python**, **Streamlit**, and **SQLite** to manage school student registration, academic profiles, and fee collection with automated receipts.

- **Interactive Web App:** [Launch Live Streamlit Application](https://github.com/rameshbhatiya/Student-record-management-system)
- **Documentation:** [View GitHub Pages](https://github.com/rameshbhatiya/Student-record-management-system)

---

## ✨ Key Features

- **📊 Dashboard Analytics:** Real-time summary of total students, active classes, total collected fees, and pending balances.
- **➕ Student Registration:** Add complete profiles including Roll No, Class, Section, Guardian Details, Address, and Fee Structure.
- **📋 Directory & Filtering:** View all student records with Class/Section filters and export data directly to CSV.
- **💳 Fee Collection & Receipts:** Process fee deposits, calculate pending balances automatically, and print instant transaction receipts.
- **🔍 Advanced Search:** Easily find student profiles by Roll Number, Name, or Mobile Number.
- **⚙️ Record Management:** Update profile details or delete records safely with confirmation prompts.

---

## 🛠️ Tech Stack

- **Language:** Python 3
- **Web Framework:** Streamlit
- **Database:** SQLite3
- **Data Manipulation:** Pandas
